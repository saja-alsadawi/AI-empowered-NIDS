# AI-empowered-NIDS

This repository contains Jupyter Notebooks used in the development of an AI-powered Network Intrusion Detection System (NIDS) using the CSE-CIC-IDS2018 dataset.

## 📂 Notebooks Included
| Notebook Name             | Description 
|---------------------------|--------------------------------------------------------------
| Dataset EDA               | Initial exploratory data analysis on the full dataset 
| Sampling                  | Stratified sampling of dataset 
| Sample Cleaning           | Cleaning sampled data (removal of nulls, duplicates, etc.) 
| Sample EDA                | Exploratory analysis on sampled data 
| Raw Data Model            | ML/DL model trained on raw dataset 
| Reduced Data Model        | Model trained after feature selection/dimensionality reduction 
| Balanced Data Model       | Model trained after applying class balancing techniques 


## 🧠 Models Used
- Machine Learning: Random Forest, Decision Tree, KNN
- Deep Learning: CNN, LSTM
- Feature Selection: XGBoost

## 📦 Dataset
The dataset is **not uploaded** due to size limitations. You can download the full CSE-CIC-IDS2018 dataset from the [official CIC website](https://www.unb.ca/cic/datasets/ids-2018.html).
